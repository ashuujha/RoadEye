# Changelog

## 0.1.0 — local synthetic MVP

- Persistent PostgreSQL/PostGIS schema, durable ingestion/jobs, replay and recovery.
- Plate consensus, bounded directed journeys, ambiguity/collision handling and revisions.
- Passage-based analytics, heartbeat coverage, scoped watchlists, alerts, review and audit.
- Local sessions, protected evidence and connected React inspection console.
- Deterministic fixtures, PostgreSQL/process/browser validation and future CI configuration.

Recognition models and real-camera adapters are not implemented. See the measured validation report for executed checks and Docker/hosted-CI limitations.

## Recorded-video extension

- Added optional local CPU vehicle/plate detection and OCR for the registered Delhi recording, with camera-local crossing counts independent of OCR.
- Added immutable recorded run configuration, outbox processing/recovery, original-frame and lossless crop evidence, and an authorized recorded console.
- Preserved synthetic scenarios and camera scope; single-camera recorded runs expose no inferred routes, calibrated speed or congestion.
- Verified first-minute inference, process crash/replay, evidence authorization and regression tests; accuracy remains unmeasured.
